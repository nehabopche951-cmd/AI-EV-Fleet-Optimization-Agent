# AI Energy & EV Fleet Optimization Agent

An **Agentic AI system** designed to optimize EV fleet operations by analyzing vehicle usage, battery status, routes, charging availability, and electricity prices.

## 🎯 Objective

To recommend **intelligent charging schedules and fleet allocation** while balancing:

* Charging cost
* Vehicle availability
* Battery health
* Operational requirements

## 🤖 AI Agents

* Fleet Agent
* Battery Agent
* Route Agent
* Charging Agent
* Cost Agent
* Optimization Agent
* Recommendation Agent

## 🔄 Workflow

**Fleet → Battery → Route → Charging → Cost → Optimization → Recommendation**

## 📊 Key Features

* EV fleet monitoring
* Battery status analysis
* Charging schedule optimization
* Electricity cost analysis
* Fleet allocation
* AI-based recommendations
* Interactive dashboard

## 🚀 Goal

To make EV fleet management **cost-efficient, reliable, and intelligent** using multi-agent AI.
